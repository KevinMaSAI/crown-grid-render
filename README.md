# 当前部署：Bot v7 + 历史记录与回放

## 在线游玩

- **游戏入口：https://crown-grid-render.onrender.com/**
- **历史记录与回放：https://crown-grid-render.onrender.com/history**

把游戏入口直接分享给朋友即可，支持 2–4 人、真人与 Bot 混合对战。服务运行在 Render 免费实例上，不需要你的电脑保持开机。免费实例闲置后首次访问可能需要等待约一分钟唤醒。


大厅和终局都有“历史记录 / 回放”入口（/history）。支持播放、暂停、1–16倍速度、前后单步、拖动到回合、全图与各玩家迷雾视角。新结束对局自动归档，包括纯 Bot 对战；原来未记录的对局无法补回。

默认经济增强 Bot（v7）包含占城权重改进，对冻结 v6 独立128局71胜57负，提升幅度有限。席位设置另有寻路增强候选，同等步数选可合兵更强的路径，对冻结v6资格64局37胜27负；独立确认尚未完成。两者组合没有显示额外收益，因此不默认合并。没有达到顶尖人类水平的验证。

线上历史与回放保存到独立的 Neon PostgreSQL 数据库，服务重启后仍可读取；已验证旧记录迁移与重启恢复。云端归档额度为200MB，达到额度后停止保存，不自动删除。

本地运行时，历史目录为 work/replays，单局2MB、总40MB；到限停止写入，不自动删除。仅归档记录可回放；记录截断或存储限额中断的文件不会作为完整回放展示。新房间采用v7。

## 开始游戏

在线游玩请打开 https://crown-grid-render.onrender.com/ 。

需要本地运行时，在项目目录执行 `npm ci` 和 `node server.js`，然后打开 http://127.0.0.1:18766 。
地图种子默认留空：每局随机生成尺寸、地形、城市和出生点。主动填写种子时，同种子、人数和队伍设置可复现同图。选项窗口显示当前种子。
仍支持 2–4 人、真人/Bot/外部 Bot 混合、自由混战和合作，操作键与原版式界面保持。

## v6 改进

主动解围、合兵与周期增兵威胁预测已经上线。对冻结 v5 的独立128局为79胜49负。完整证据与限制见 outputs/BOT-V6-REPORT.md。新房间使用v6，已有房间保留原版本。

## v5 改进

- 攻击已知主城前，考虑排在我方之前行动的敌人能否先补兵。
- 追踪逼近的大部队，允许其出发格重新进入迷雾。
- 按抵达时限和可送达兵力选援军，不再只因距离近就先搬小股兵。
- 保留两步防杀、一步斩首和队友路径避让。
